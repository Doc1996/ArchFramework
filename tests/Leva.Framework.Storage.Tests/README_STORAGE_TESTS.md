# Leva.Framework.Storage.Tests

`Leva.Framework.Storage.Tests` verifies the stable contracts and value types from `Leva.Framework.Storage`. These tests focus on storage values, errors, repository contracts, and journal contracts rather than provider-specific behavior.

## Coverage

`StorageValueTests` - Verifies storage versions, next-version behavior, invalid version guards, and stored value metadata.
`StorageErrorTests` - Verifies common storage error codes and messages.
`StorageContractTests` - Verifies that repository and journal contracts can be implemented and used.
